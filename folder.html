One setting

Turn on folder access in Brave.

Brave switches folder access off by default, so the extension can't see which transcripts you already have. One setting fixes it.

  1. Click Open Brave settings below.
  2. Set File System Access API to Enabled.
  3. Click Relaunch, then open the extension and click Connect.
